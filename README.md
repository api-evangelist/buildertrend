# buildertrend

Buildertrend — cloud construction-management software for residential builders, remodelers, and specialty contractors.

Buildertrend operates a REST API at `api.buildertrend.com`, but it is gated for partners and integrators — every probed endpoint returns `401 Unauthorized`, there is no public developer portal at `developers.buildertrend.com`, no self-serve API key signup, and no published OpenAPI specification. This repo therefore profiles Buildertrend as a non-public (partner-only) API provider and captures the public marketing, integrations, support, and corporate surface only. The `apis.yml` `apis:` list is intentionally empty — no placeholder specs have been generated.
